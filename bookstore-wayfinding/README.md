# 书山有路 · 大型书城找书路线系统

读者输入「出发位置 + 楼层 + 书区（+ 收银台）」，系统综合**通道距离、拥挤程度、
扶梯/电梯偏好**，在楼层拓扑图上做加权最短路规划，并返回**中文分步指引**
（如“右转，转入一层主通道，步行约 100 米”），而不是节点编号。
管理员可在后台维护书区节点与通道边。

零第三方依赖，仅用 Python 3 标准库（`http.server` + `sqlite3`）。

## 启动

```bash
python3 server.py
# 读者端 http://localhost:8000/
# 管理端 http://localhost:8000/admin.html
```

首次启动自动建库并播种（删除 `data/bookstore.db` 可重置）。

## 功能

### 读者端 `/`
- 选择出发位置（入口/扶梯/电梯等）、目标楼层、书区，可勾选“找完书去该层收银台”
- 三套路线偏好对比：**综合推荐 / 人少舒适（倾向电梯、规避拥挤）/ 扶梯优先**
- 每一步的中文指引：方向（正北/东南…）、转向（左转/右转/掉头）、通道名、
  米数、扶梯/电梯乘梯与换层、拥挤提醒、到达提示
- SVG 楼层平面图：通道、书区、扶梯/电梯、收银台、拥挤度标记；
  推荐路线红色叠加，**点击任一步骤，地图自动定位到该楼层并闪烁高亮对应路段**
- 全程距离、预计分钟数、乘梯次数、途经楼层、拥挤路段摘要

### 管理端 `/admin.html`
- 节点：新增/编辑/删除（编码、名称、楼层、类型、坐标、拥挤度）
- 通道边：新增/编辑/删除/一键停用启用（停用通道立即不参与寻路）
- 类型：步行通道 walkway / 扶梯 escalator / 电梯 elevator
- 服务端校验：编码格式、必填项、引用完整性（被引用的节点禁止删除）

## 路径模型

- 权重以“等效秒数”计：
  - 步行 = 距离 / 步速 × 拥挤系数（1 级 ×1.0，2 级 ×1.5，3 级 ×2.3）
  - 扶梯 = 每层 22s × 拥挤 × 偏好系数
  - 电梯 = (每层 14s + 呼梯等待 18s) × 拥挤 × 偏好系数
- 多目标（书区 → 收银台）按航段分别做 Dijkstra 后拼接
- 三种偏好分别求解并去重，按总耗时排序返回
- 指引生成时，连续同方向步行边合并，遇到转弯自动拆成独立步骤

## 目录

```

core/db.py           SQLite 建库/播种/查询
core/pathfinder.py   图模型 + 加权 Dijkstra + 多偏好规划
core/directions.py   路径 → 中文分步指引
data/seed.py         3 层楼、51 节点、56 通道边的种子拓扑
static/              读者端与管理端页面（原生 JS + SVG）
```
