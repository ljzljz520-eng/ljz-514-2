# 📚 大型书城找书路线系统

用户选择想去的 **楼层 / 书区 / 收银台**，系统综合
**通道距离、扶梯/电梯/楼梯耗时、实时拥挤程度**，给出最多 3 条候选路线，
并把结果翻译成**自然语言的“每一步怎么走”**（不只是节点编号），
同时在 SVG 楼层平面图上高亮路径。管理员可在页面上维护书区节点和通道边，
改动即时生效并落盘。

零第三方依赖（Node.js 原生 `http` + 原生前端，无需构建）。

## 快速开始

```bash
node scripts/seed.js     # 1) 生成示例书城数据（4 层，59 节点 / 84 边）
ADMIN_KEY=your-secret npm start   # 2) 启动服务（默认 3000 端口）
# 打开 http://localhost:3000
ADMIN_KEY=your-secret npm test    # 端到端 API 测试（需先启动服务，密钥与服务一致）
```

- 管理员密钥：通过环境变量 `ADMIN_KEY` 设置；未设置时每次启动会随机生成一个密钥并打印到服务端控制台（重启即失效）
- 重新播种：先停服务，再 `node scripts/seed.js`（服务会监听数据文件自动刷新缓存）

## 功能一览

### 用户端
- 入口 → 书区（**去程**）与 书区 → 收银台（**离场**）分别给出最多 3 条方案；
- 每张方案卡显示：预计分钟、总米数、经过楼层、拥挤路段数、特征标签
  （用时最短 / 最通畅 / 电梯直达 / 乘坐扶梯 / 走楼梯更省时）；
- **分步指引时间线**，例如：
  - “沿入口大厅向「1楼南口」方向走约 7 米”
  - “在「1楼南口」左转，进入西南通道，再走约 41 米（当前比较拥挤，注意避让）”
  - “在「1楼西侧电梯厅」乘电梯上行，到 2 楼，请按 2 楼按键（不到 1 分钟）”
  - “到达 2 楼「文学区」。”
- SVG 平面图：去程蓝色描边、离场橙色描边，普通通道按拥挤度染色，
  可切换楼层查看，起终点带 🚩📖💰 徽标。

### 管理端（密钥登录）
- 节点 CRUD：名称 / 类型（书区、扶梯、电梯、楼梯、收银台…）/ 楼层 / 坐标，
  支持在平面图上**点击自动取坐标**；
- 边 CRUD：通道 / 扶梯 / 电梯 / 楼梯，两端点下拉选择，
  通道距离留空时按坐标自动计算，可调整拥挤度与通道名；
- 删除节点会连带删除挂接的边；同层/跨层类型校验；所有写入即时持久化到
  `data/graph.json`，重启不丢，路线推荐立即反映新数据与新拥挤度。

## 路线是怎么推荐的

图模型（`src/graph.js`）：节点 + 双向边；边权统一折算为“等效秒数”。

| 边类型 | 基础耗时 | 拥挤度系数 (0畅通 / 1较少 / 2拥挤 / 3很挤) |
|---|---|---|
| 通道 corridor | 距离 / 1.2 m·s⁻¹ | 1.0 / 1.15 / 1.40 / 1.80 |
| 扶梯 escalator | 30 s/层 | 1.0 / 1.25 / 1.60 / 2.00 |
| 电梯 elevator | 25 s 等梯 + 12 s/层 | 1.0 / 1.20 / 1.50 / 1.90 |
| 楼梯 stairs | 12 s/层 | 1.15 / 1.35 / 1.75 / 2.30 |

- 单条最优：**Dijkstra**；最多 3 条不同方案：**Yen K 最短路径**；
- 通道距离 = 画布坐标欧氏距离 × 0.1（一层约 100m × 70m，见 `src/geo.js`）；
- 转向由相邻通道的方位角计算（直行 / 左转 / 右转 / 斜向 / 掉头），
  拥挤 ≥ 2 级时在指引中插入避让提示（`src/directions.js`）。

## HTTP 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/meta` | 楼层、节点/边类型、拥挤度字典 |
| GET | `/api/nodes?floor=` | 节点列表 |
| GET | `/api/edges?floor=` | 边列表 |
| POST | `/api/route` | 入参 `{floorId, zoneId, cashierId, entranceId?}`，返回 `go[]` / `back[]` 方案 |
| POST/PUT/DELETE | `/api/nodes[/:id]` | 管理端（需请求头 `X-Admin-Key`） |
| POST/PUT/DELETE | `/api/edges[/:id]` | 管理端（需请求头 `X-Admin-Key`） |

```bash
curl -X POST http://localhost:3000/api/route -H 'Content-Type: application/json' \
  -d '{"floorId":2,"zoneId":"f2-lit","cashierId":"f1-cash-a"}'
```

## 目录结构

```
scripts/seed.js       4 层示例书城数据生成（含扶梯/电梯/楼梯、主题书区）
src/server.js         HTTP 服务、路由、鉴权、参数校验
src/store.js          JSON 存储（缓存 + 写穿透 + 文件变更自动重载）
src/graph.js          建图、边权、Dijkstra、Yen K 最短路径
src/directions.js     节点序列 → 中文分步指引 + 方案标签
src/geo.js            坐标↔米比例尺
public/               index.html / app.js / styles.css（SVG 地图、管理台）
test/api.test.js      端到端测试
data/graph.json       运行时数据（管理员的修改保存在这里）
```
